===================================================
                   WEST VPN (Портативная версия)
===================================================

ИНСТРУКЦИЯ ПО УСТАНОВКЕ НА ЛЮБОЙ ПК:

1. УСТАНОВКА РАСШИРЕНИЯ В БРАУЗЕР (Cent Browser, Chrome, Edge, Brave, Яндекс):
   - Откройте в браузере страницу: chrome://extensions
   - Включите переключатель «Режим разработчика» (Developer mode) в правом верхнем углу.
   - Нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).
   - Выберите папку «extension» внутри этой папки west.
   - (Либо просто перетащите файл west.crx на страницу chrome://extensions).

2. ЗАПУСК ЯДРА:
   - Запустите двойным кликом файл «Запустить West.bat».
   - Окно запустит локальный West Core (Xray) на портах 10808 (SOCKS5), 10809 (HTTP) и мост управления 19090.

3. ИСПОЛЬЗОВАНИЕ:
   - Нажмите на иконку «W» (West) на панели браузера.
   - 46 серверов уже встроены в клиент. Выберите сервер и нажмите кнопку подключения.
   - Режимы маршрутизации:
     * «Весь браузер» — весь трафик браузера идет через VPN.
     * «Сайты из списка» — только нужные сайты (YouTube, Discord, Instagram и др.) идут через VPN.
     * «Все, кроме списка» — все через VPN, кроме исключений (банки, Госуслуги).
