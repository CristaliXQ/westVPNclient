# West VPN Client

Автономный портативный VPN-клиент для Chromium-браузеров (Cent Browser, Chrome, Edge, Brave, Яндекс) с поддержкой V2Ray / VLESS / Reality / Trojan / VMess и гибкой маршрутизацией доменов.

---

## Возможности

* **Маршрутизация**:
  * «Весь браузер» (Global Proxy).
  * «Сайты из списка» (Whitelist) — YouTube, Discord, Twitter / X, Instagram, GitHub, ChatGPT.
  * «Все, кроме списка» (Blacklist) — банковские и госсервисы напрямую, остальное через VPN.
* **Автоподбор (Лучшая страна)**: автоматический опрос доступных серверов и выбор узла с минимальным пингом.
* **Встроенный тест пинга**: точный замер сетевой задержки (TCP Handshake) по всем серверам в один клик.
* **Полная автономность**: ядро Xray Core упаковано в папку `bin/`. Не требуется установка стороннего софта.

---

## Быстрый старт

1. **Установка расширения в браузер**:
   * Откройте страницу `chrome://extensions`
   * Включите **«Режим разработчика»** (в правом верхнем углу).
   * Нажмите **«Загрузить распакованное расширение»** и выберите эту папку `west`.
   *(Либо перетащите файл `west.crx` на страницу расширений)*.

2. **Запуск ядра**:
   * Запустите файл `Start_West.bat`.
   * Откроется консоль локального ядра (127.0.0.1:19090 и SOCKS5 127.0.0.1:10808).

3. **Подключение**:
   * Нажмите на иконку **W** на панели браузера.
   * Выберите узел или нажмите **«Автоподбор (Лучшая страна)»**.
   * Нажмите большую круглую кнопку включения.

---

## Горячие функции в интерфейсе

* **Кнопка «⚡ Тест пинга»** в окне выбора серверов: тестирует реальную задержку по всем серверам и сортирует их по скорости.
* **Кнопка перезагрузки расширения** (круглая стрелка внизу окна): моментально обновляет код расширения из папки в один клик (`chrome.runtime.reload()`).
* **Кнопка обновления подписки**: загружает свежие серверы по ссылке и автоматически фильтрует нерабочие узлы.
