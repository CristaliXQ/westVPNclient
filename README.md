# West VPN Client v1.5.0

Автономный кроссплатформенный VPN-клиент и менеджер маршрутизации для **Linux** и **Windows**. Работает со всеми Chromium-браузерами (Google Chrome, Brave, Cent Browser, Edge, Chromium, Яндекс) и LibreWolf / Firefox. Поддерживает **V2Ray / VLESS Reality / Trojan / VMess / Hysteria2**, раздельную маршрутизацию серверов по доменам и выделенный туннель для режима задач Gemini (США).

---

## 🔥 Ключевые возможности v1.5.0

* **🐧 Полная кроссплатформенность (Linux + Windows)**:
  * Нативная работа службы ядра на Linux (Ubuntu, Debian, Arch Linux, Manjaro, Fedora, openSUSE).
  * Автоматический поиск и запуск нативного ELF-бинарника Xray (`core/xray`, `/usr/bin/xray`, `/usr/local/bin/xray` или `PATH`).
  * Полный комплект скриптов управления: `start_service.sh`, `stop_service.sh`, `restart.sh`, скрипт автоустановки `install_linux.sh` и готовый сервис `systemd` (`west-client.service`).
  * Безопасное управление процессами через `/proc` и `psutil` с сигналами `SIGTERM` / `SIGKILL` без сторонних зависимостей.

* **🤖 Режим задач Gemini (США • US Tasks Proxy)**:
  * Выделенный высокоскоростной туннель на порту `10820` / `10821` специально для `gemini.google.com`, Google AI Studio, Code Execution и Google Tasks через проверенный американский сервер Reality.
  * Работает независимо от того, какой сервер выбран основным для остального трафика.
  * Включение в 1 клик через неоновый переключатель в шапке.

* **🎯 Раздельная привязка серверов по сайтам (Per-Domain Server Routing)**:
  * Выбирайте индивидуальный сервер из подписки для любого конкретного домена прямо из шапки расширения (например, Gemini -> США, Claude -> Великобритания, Wikipedia -> Швеция).
  * Готовый пресет из 14 доменов Gemini и Google AI Studio в 1 клик.

* **🛡️ 100% Защита основной сети (Zero Network Conflict)**:
  * **YouTube Direct (Zapret winws / nfqws / tpws)**: видеопотоки YouTube идут напрямую мимо шифрования VPN на максимальной скорости вашего провайдера.
  * **Изоляция Localhost & LAN**: `127.0.0.1`, локальные базы данных, порты разработки и роутеры (`192.168.*`, `10.*`) никогда не перехватываются туннелем.
  * **Прямой доступ к сервисам РФ**: Госуслуги, Сбер, Т-Банк, Яндекс, VK и другие российские ресурсы идут напрямую без капч и блокировок.
  * **Игры и стороннее ПО**: расширение работает исключительно на уровне браузерного PAC-скрипта, не трогая системные сетевые адаптеры, игры (CS2, Roblox, Dota) или Steam.

* **⚡ Умная мульти-ядерная отказоустойчивость**:
  * Собственная служба ядра **West Core** (`127.0.0.1:10850`, `10818` SOCKS5, `10820` US SOCKS5).
  * Мгновенное резервное переключение на внешний **v2RayTun / Sing-Box** (`10808`) при отсутствии локальной службы без разрыва связи.
  * Кнопка «⚡ Мин. пинг» с автоматическим скорингом стабильности узлов.

* **🎨 Современный темный интерфейс (Dark Ergonomic UI)**:
  * Чистая OLED-палитра, отсутствие визуального шума, быстрый селектор сервера текущей вкладки.

## 🚀 Быстрый старт: Linux

### 1. Автоматическая установка в 1 клик:
Запустите в терминале из папки проекта:
```bash
chmod +x install_linux.sh
./install_linux.sh
```
Скрипт автоматически:
1. Проверит наличие Python 3 и библиотеки `psutil`.
2. Определит архитектуру процессора (`x86_64` или `arm64`) и при необходимости скачает нативный бинарник Xray с официального репозитория XTLS.
3. Установит права на запуск и зарегистрирует службу `systemd` (`~/.config/systemd/user/west-client.service`).

### 2. Запуск службы на Linux:
* **Через systemd (фоновый демон с автозагрузкой):**
  ```bash
  systemctl --user enable --now west-client
  systemctl --user status west-client
  ```
* **Или напрямую скриптами:**
  ```bash
  ./start_service.sh    # Запуск в фоне
  ./stop_service.sh     # Чистая остановка
  ./restart.sh          # Перезапуск
  ```

### 3. Установка расширения в браузер на Linux:
* **Chromium, Google Chrome, Brave, Cent, Vivaldi:**
  1. Откройте `chrome://extensions`
  2. Включите **«Режим разработчика»** (Developer mode).
  3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку проекта.
* **LibreWolf / Firefox:**
  * Перетащите файл `west-vpn-client.xpi` в окно браузера и подтвердите установку.

## 🚀 Быстрый старт: Windows

### 1. Запуск службы ядра:
* Запустите файл `start_service.vbs` (тихий фоновый запуск без консольного окна) или `start_service.bat`.
* Служба автоматически поднимет порты:
  * `10818` — Основной SOCKS5 прокси
  * `10819` — Основной HTTP прокси
  * `10820` — Выделенный SOCKS5 прокси для Gemini (США)
  * `10821` — Выделенный HTTP прокси для Gemini (США)
  * `10850` — Локальный API-сервер управления

### 2. Установка расширения:
* В Chrome / Brave / Cent / Edge: `chrome://extensions` -> Включить режим разработчика -> Загрузить распакованное.
* В LibreWolf / Firefox: перетащите `west-vpn-client.xpi` в браузер.

## 📋 Управление маршрутами

В окне расширения на вкладке **«Маршруты сайтов»** доступны:
1. **Выделенные серверы**: таблица привязок конкретных сайтов к серверам из подписки (например, `gemini.google.com` -> США, `claude.ai` -> Великобритания).
2. **В VPN**: список доменов, идущих через основной VPN-сервер.
3. **В Direct**: список исключений, открывающихся напрямую мимо VPN.
