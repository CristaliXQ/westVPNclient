# West VPN Client v1.4.0

Автономный портативный VPN-клиент и менеджер маршрутизации для Chromium-браузеров (Cent Browser, Google Chrome, Brave, Edge, Яндекс) и LibreWolf / Firefox с поддержкой **V2Ray / VLESS / Reality / Trojan / VMess / Hysteria2**, многосерверной маршрутизацией по сайтам и выделенным режимом задач Gemini (США).

---

## 🔥 Ключевые возможности v1.4.0

* **🤖 Режим задач Gemini (США • US Tasks Proxy)**:
  * Выделенный высокоскоростной туннель на порту `10820` / `10821` специально для `gemini.google.com`, Google AI Studio, Code Execution и Google Tasks через проверенный американский сервер Reality.
  * Работает независимо от того, какой сервер выбран основным для остального трафика.
  * Включение в 1 клик через неоновый переключатель в шапке.

* **🎯 Раздельная привязка серверов по сайтам (Per-Domain Server Routing)**:
  * Выбирайте индивидуальный сервер из подписки для любого конкретного домена прямо из шапки расширения (например, Gemini -> США, Claude -> Великобритания, Wikipedia -> Швеция).
  * Готовый пресет из 14 доменов Gemini и Google AI Studio в 1 клик.

* **🛡️ 100% Защита основной сети (Zero Network Conflict)**:
  * **YouTube Direct (Zapret winws)**: видеопотоки YouTube идут напрямую мимо шифрования VPN на максимальной скорости вашего провайдера.
  * **Изоляция Localhost & LAN**: `127.0.0.1`, локальные базы данных, порты разработки и роутеры (`192.168.*`, `10.*`) никогда не перехватываются туннелем.
  * **Прямой доступ к сервисам РФ**: Госуслуги, Сбер, Т-Банк, Яндекс, VK и другие российские ресурсы идут напрямую без капч и блокировок.
  * **Игры и стороннее ПО**: расширение работает исключительно на уровне браузерного PAC-скрипта, не трогая системные сетевые адаптеры, игры (CS2, Roblox) или Steam.

* **⚡ Умная мульти-ядерная отказоустойчивость**:
  * Собственная служба ядра **West Core** (`127.0.0.1:10850`, `10818` SOCKS5, `10820` US SOCKS5).
  * Мгновенное резервное переключение на внешний **v2RayTun** (`10808`) при отсутствии локальной службы без разрыва связи.
  * Кнопка «⚡ Мин. пинг» с автоматическим скорингом стабильности узлов.

* **🎨 Современный темный интерфейс (Dark Ergonomic UI)**:
  * Чистая OLED-палитра, отсутствие визуального шума, быстрый селектор сервера текущей вкладки.

## 🚀 Быстрый старт

### 1. Установка в Google Chrome / Cent Browser / Brave / Edge:
1. Откройте `chrome://extensions`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и укажите папку расширения.
4. Закрепите значок West VPN Client на панели браузера.

### 2. Установка в LibreWolf / Firefox:
* Перетащите файл `west-vpn-client.xpi` в окно браузера и подтвердите установку.

### 3. Запуск службы ядра:
* Запустите файл `start_service.vbs` (фоновый запуск без черного окна консоли) или `start_service.bat`.
* Служба автоматически поднимет порты:
  * `10818` — Основной SOCKS5 прокси
  * `10819` — Основной HTTP прокси
  * `10820` — Выделенный SOCKS5 прокси для Gemini (США)
  * `10821` — Выделенный HTTP прокси для Gemini (США)
  * `10850` — Локальный API-сервер управления

## 📋 Управление маршрутами

В окне расширения на вкладке **«Маршруты сайтов»** доступны:
1. **Выделенные серверы**: таблица привязок конкретных сайтов к серверам из подписки.
2. **В VPN**: список доменов, идущих через основной VPN-сервер.
3. **В Direct**: список исключений, открывающихся напрямую мимо VPN.
